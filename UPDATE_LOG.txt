This file documents the recent components and dependencies added to the project.
If you are pulling these changes from GitHub on a new machine, please follow the instructions below.

=======================================================
1. NEW NPM PACKAGES TO INSTALL
=======================================================
You MUST install the following packages to ensure the new animations and scroll effects work. Please run this command in your terminal:

npm install framer-motion @studio-freight/lenis

(Alternatively, if you run `npm install` to sync your package.json, they should install automatically).

=======================================================
2. NEW COMPONENTS ADDED
=======================================================
The following custom UI components were added to the codebase during this session:

- src/components/ui/hero-3.tsx (AnimatedMarqueeHero component for the landing page header)
- src/components/ui/feature-section-with-hover-effects.tsx (Replaced "Why Choose Aaspass")
- src/components/ui/zoom-parallax.tsx (Dynamic scroll effect for the "Ready to Join" section)
- src/components/ui/interactive-accordion.tsx (Expandable "How it Works" animated list)
- src/components/OperationToggle.tsx (New toggle button for filtering between Home/Shop in the marketplace)

=======================================================
TROUBLESHOOTING
=======================================================
If you encounter any module resolution errors after cloning or pulling:
1. Delete the `node_modules` folder and `package-lock.json` file.
2. Run `npm cache clean --force`
3. Run `npm install` to freshly resolve all packages.
